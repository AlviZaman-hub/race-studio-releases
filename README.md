# Race Studio

Make satisfying race videos (Maze Race, Ring Escape, Marble Elimination, Territory War) for YouTube Shorts, TikTok and Reels.

## Download
Get **RaceStudio.zip** from the [latest release](https://github.com/AlviZaman-hub/race-studio-releases/releases/latest).

- **Mac:** unzip, move the folder to Documents, double-click `Start Race Studio.command`
- **Windows:** unzip, double-click `Start Race Studio.bat`

The app updates itself: it checks this repo's `latest.json` every time it opens.
